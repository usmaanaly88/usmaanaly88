## 🐞 How I Report Bugs

A good bug report saves everyone time. This is the structure I follow:

```
Title:        Short, specific summary of the issue
Environment:  Device / OS / Browser / Build version
Severity:     Critical | High | Medium | Low
Steps:        1. ...  2. ...  3. ...
Expected:     What should happen
Actual:       What actually happened
Evidence:     Screenshot / screen recording / logs
```
